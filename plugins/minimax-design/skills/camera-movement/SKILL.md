# 运镜设计

把“镜头要有什么感觉”转成可观察的摄影机行为。先决定观众需要看到什么，再选择构图和运动。当创作意图明确，且用户要求撰写或优化完整提示词时，默认先交付可直接用于生成的整版提示词，再按同一版分镜制作可播放的本地白模供对照打磨。

这是用户的独立创作 skill，不是模型厂商官方技能。六种起始参考来自一则已核对画面与字幕的小红书视频，见 [来源记录](references/source-analysis.md)。技术拆解和提示词模板是本 skill 的实用扩展，不冒充原视频完整讲解或标准术语。

## 工作流程

### 默认交付顺序：完整提示词初稿 → 对应白模 → 双稿对照打磨

只有创作意图明确并要求撰写或优化完整提示词时，才启动这套默认流程。例如“用 SD2.5 给这一幕写完整分镜”。讨论灵感、寻找方向、积累参考时只推进当下的探索；询问技能怎么用、仅提到技能名称时只回答问题。用户单独指定交付物时，按其指定范围执行。

灵感讨论转入「写剧本」时，用当前确认的内容写完整剧本，按场景交代地点、时段、人物动作、旁白和台词。剧本成稿保存为本地 Markdown 草稿并给出文件链接；每次修改剧本，以当前稿或用户点名的版本为底，只改点名内容及必要衔接。同步更新本地 Markdown；已有下游场景提示词时，仅同步受影响的部分。用户要为剧本设计或复刻场景时，将这份草稿及已确定的图片、创作意图交给[剧本场景参考图](../scene-reference/SKILL.md)，接着写逐场静帧提示词。

- **完整初稿。** 先按用户要求的格式写出能直接用于生成的整版提示词，包括已采用素材的职责、时间节点、表演、机位、运镜和衔接。以这份文本作为白模的拍摄依据。
- **制作预演。** 用简化人物、几何体与必要地标，将同一时间线上的站位、动作先后、遮挡、焦点、摄影机路径与剪点演出来。用角色英文名区分人物，必要时以色块区分服装或道具。
- **一起核对。** 运行并查看本地白模，再把完整初稿与可播放预演一并交付。按镜头核对两者的走位、景别和节奏。制作或播放受阻时交付可用的提示词并说明具体阻塞。
- **最小修改。** 每轮收到反馈，默认以用户指定的版本（未指定时用当前版）为底稿，只修改点名的位置和必要的衔接、引用或时间节点。涉及画面或动作的变动，同步调整对应分镜和预演片段；只改措辞时沿用原白模，只修白模偏差时沿用原提示词。其余原文、镜头和参数保持原样。定稿沿用核对过的这一对。
- **参考分工。** 如果白模实际作为生成参考输入，明确它只指导指定的动作、空间和运镜，外观由实际采用的角色与场景参考定义。是否上传白模及生成，按用户授权执行。

用户明确要求跳过白模、直接写提示词，或只改文本时间节点时，按其指定的交付范围处理。可复用已有的对应白模。

1. **锁定当前契约。** 从对话和已有稿件确认剧情、人物位置、行进方向、时长、画幅、焦点主体、允许的剪辑方式、必须保留的动作。
2. **确定视觉任务。** 每镜说明一个首要目的，例如交代空间、显露表情、展示关系、追随动作、揭示新信息。按目的选镜头，不强行凑齐六种，也不默认所有镜头都运动。
3. **拆开五个维度。** 分别确定：构图/景别；机位高度和朝向；摄影机实际运动；焦点对象；人物动作与视线。过肩是构图，鸟瞰是视角，环绕才是运动。人物看向谁与摄影机对焦谁独立指定。
4. **写出起点—路径—终点。** 明确从谁的哪一侧、什么高度开始，沿什么方向移动，相对主体距离如何变化，经过什么可见空间，最终停在哪个景别和构图。方向易歧义时写“从人物背后经其左侧绕至正面”，不只写“向左转”。
5. **控制复杂度。** 单镜优先一个主要运动，可配一个必要焦点变化。复杂连续镜头按先后阶段描述，时间仍属于同一镜头；不要同时塞入高速环绕、变焦、升降、摇镜和多次转焦。
6. **检查连续性，再交付。** 对照下方检查表；使用 [六种镜头库](references/shot-library.md) 选具体写法。涉及一镜到底或稳定主体的要求，另读 [连续镜头与焦点](references/continuity.md)。

## 描述格式

按用户需要输出；要求“完整提示词、不要说明”时只给整合后的可复制文本。多镜分镜使用连续且不重叠的时间段，时长遵循当前任务约束，不将历史项目的 30 秒上限当作所有项目或模型的能力限制。

推荐单镜结构：

> 【镜头编号｜开始–结束秒｜镜头目的】从〔高度、方位、景别、前后景关系〕开始。〔摄影机〕以〔节奏〕沿〔路径〕运动至〔终点构图〕。〔主体〕在此期间完成〔可见动作/微表情〕，视线朝向〔对象〕。焦点〔始终保持/明确转移〕在〔对象〕。以〔停稳/继续运动/切镜〕衔接下一镜。

没有必要的信息不机械补齐；不要留下括号占位符。技术词后接可见描述，避免“高级感、电影感、史诗运镜”等形容词代替实际动作。

## 核验清单

- 摄影机平移、升降与原地摇/俯仰分开表达；推进与变焦分开表达，不把改变焦距说成走近。
- 焦点转移不等于镜头切换；浅景深不等于改变角色注意力。
- 主体能否一直入画，终点画面是否满足剧情；前景遮挡会不会遮住关键表演。
- 双人朝向、左右关系、视线和地标一致；环绕穿越轴线时通过连续可见路径交代，不让空间突然翻转。
- 镜头没有穿过实体人物、树干或墙面；无叙事依据时不让角色自行转身迎合摄影机。
- 一镜到底的段落里没有隐含硬切、叠化、换机位、遮挡偷切或未交代的瞬间跳跃。
- 约束只针对实际失败风险。用肯定的视觉结果描述主体，再补必要的禁止事项，不堆砌无关负面词。
- 引用素材只列实际采用项，按媒体类型连续编号并同步正文；不带文件名、不列未采用素材。所有角色采用已确定的英文名；未知姓名先核实，不擅自命名。

## 与其他技能协作

- 本 skill 负责机位、构图、运动、焦点及镜头衔接，可独立调用。
- 用户要求撰写或优化 Seedance 2.5 提示词时，读取宿主技能目录里的官方 `sd25-pe`；使用 MiniMax Design 插件时可直接读取同包的 `../sd25-pe/SKILL.md`。由它指导多模态分工、表演、整体提示词与参数区分，本 skill 细化镜头。
- 不修改官方 skill，不将本 skill 宣称为官方；不自动引入其他模型版本。官方文件不存在时说明并定位官方来源，不能声称已加载。
- 不因运镜写作自动打开项目或生成视频。实际项目操作遵循用户授权和对应 MCP 工作流。
