# 角色换装与三视图

衣物参考图默认交付一张无人正面整套穿搭图。以隐形人台效果呈现衣物穿在身上的自然体积和垂坠，从领口到鞋尖完整入画，使用素净中性背景。按原图还原穿法、版型、颜色、材质、叠穿层次与配饰，仅替换用户点名的单品。整套连续呈现，不拆成单品拼贴；去除参考截图中的人物、界面和文字。用户当次明确指定的画幅、陈列方式或服装要求优先。

1. **确定衣物。** 用户给搭配图时，按其指定逐层提取服装、配饰、颜色和穿法，包括领口、下摆、袖口、腰线和鞋。已有确认的衣物参考图就直接使用。只有在用户要看衣物图，或明确要先提取整套衣服时，才单独生成衣物图。穿搭照片中的模特只提供衣服。
2. **找到身份原图。** 在对应画布核对角色的英文名、资产标注、版本和原始设定图，或打开可核实来源的本地原文件。对照大头像和三视图的脸、发型、耳朵、体型与版式。有多套同名换装图时，追溯至建立角色身份的原始资产。已换装的衍生图仅可说明服装细节；如果手里只有衍生图且无法查到原图，请用户指定原图后再上身。记下本次使用的原图资源及版本或本地路径。
3. **给原图换装。** 使用实际的参考图编辑入口，以身份原图为底，衣物图指导穿搭。让大头像可见的领口和三视图各角度穿同一套服装，保留原图布局、脸部比例、发色和身体比例。查看完整换装图，先核对身份与各视角的领口、叠穿顺序、裤型、鞋和配件；发现漂移时回到身份原图修正。
4. **本地打码。** 需要正侧面打码的交付，在确认过的换装图上进行像素处理。逐一定位三视图里正面、侧面全身小人各自的头部，框住耳尖、发际、整个侧脸轮廓直到下巴，保留领结、衣领和肩部。单独展示身份的大头像和背面视图保留清晰。按画面实际布局取像素坐标。使用本技能的 [Pillow 工具](../scripts/mosaic_turnaround.py)，写出新的 PNG；如本地已有等价工具也可使用。打码这一步不调用生图。
5. **验收与归档。** 放大两个头像，查看耳尖、鼻尖与下巴，再缩回全图检查衣物、身份大头像和背面。用户只要本地交付就返回成品；用户要求存入画布时，将最终验收版本放进指定项目和分类，按用户指定的英文名、造型名或资产名登记。重新打开画布中实际保存的版本，核对预览和素材职责，记录资源及版本。源设定图继续作为以后的身份基底。

## 使用本地工具

需要 Python 和 Pillow。坐标采用完整图片的左上角为原点，按左、上、右、下填写；右、下为框外第一列和第一行。先打开和测量实际图片。以下大写项替换成实际像素数。工具完成后打开输出检查覆盖范围。

```text
python mosaic_turnaround.py input.png output.png --front X1 Y1 X2 Y2 --side X1 Y1 X2 Y2
```
