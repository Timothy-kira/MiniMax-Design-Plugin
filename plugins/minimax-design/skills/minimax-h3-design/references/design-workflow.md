# MiniMax Design 工作流

依据 [MiniMax Design - 手册与指南](https://my.feishu.cn/wiki/VEoVwpfCKiTHvHkAGQ7cQJxCncf)，读取日期：2026-10-16。UI 名称与功能可变，实际操作前看当前界面。

## 入口与账号

手册顶部列国内版 `https://design.minimax.cn/`、海外版 `https://design.minimax.io/`，并明确两边账号不互通。手册其他章节及 H3 手册仍出现 `https://design.minimaxi.com/`。这些是原文同时存在的入口记录；不要擅自把旧域名认定失效或把不同版本账号当成同一个。

先沿用户正在使用的版本和项目继续。优惠积分、订阅价格、可用模型、客户端支持、区域差异和消耗方式均需即时核对，避免把“新用户 3000 积分”等活动描述做成永久规则。

## 四种开始方式

| 用户现状 | 入口与处理 |
| --- | --- |
| 知道要做什么 | 直接描述目标，包含受众、产品/主题、卖点、渠道、时长画幅与风格 |
| 有任务但不知道流程 | 浏览 Skill 广场或我的 Skill，选匹配流程后“去对话中试试” |
| 希望快速套用结构 | 选择提示词模板，替换真实信息并检查遗漏 |
| 已有素材或历史项目 | 上传图片、视频、音频、3D 资产，或导入已有项目；手册提到 ZIP 导入 |

通用流程：商业目标 → 素材 → 可选 Skill/模板 → 需求 → Agent 规划 → 执行/修改 → 成品 → 复用方法。目标写成要让哪类受众理解/相信/采取什么行动，再落实画面；不要只列视觉形容词。

## 画布、导出与资产

- 手册称画布素材默认存于本地，也可重新下载。交付时仍检查文件真实存在、可打开，不能把缓存视为完成备份。
- 角色、场景、风格包、道具及中间步骤可保存至资产中心，用于新项目。手册说明右键可见相应选项；当前版本以实际菜单为准。
- 左侧项目栏用于创建、整合和管理项目。复杂项目库操作应再读原文所链项目库说明，不自行补出同步或备份机制。
- 交付最终成片时核对最终文件，而不只核对画布预览。

## 剪辑、导演台与工具

在画布添加节点，选择导演台/视频剪辑，再打开节点内相应插件。用自然语言调整，导出画布产物后继续后续创作。

| 功能 | 手册所述用途 |
| --- | --- |
| 3D 导演台 | 摆放角色素体、机位与姿态，快速制作分镜参考，可多人 |
| 视频剪辑 | 裁剪、拼接、调序；转场、滤镜、贴纸；添加/修改字幕内容、时间和位置；调整比例、布局和基础视觉效果 |
| 节点 Toolbar 工具 | 手册列多角度、多宫格分镜、打光、水印等工具，按当前节点实际选项使用 |
| 全景图预览 | 360° 环视、缩放、自动旋转，用于场景预览 |

镜头编排、字幕时码或片段顺序问题优先考虑剪辑层；内容、身份、动作或事实错误回到相应素材/分镜/生成片段。不要无故重做整个项目。

## 修改反馈与商业验收

按“保留什么 + 修改什么 + 为什么 + 期望结果”把反馈落到具体镜头/时间段。例如：保留产品特写，将开头等待画面缩短，因为投放需要更快进入主题，期望前两秒展示实际使用场景。

手册的商业检查项：目标是否明确、前三秒是否有效、核心卖点是否突出、产品信息是否准确、品牌视觉是否统一、文字字幕是否正确、节奏是否匹配渠道、输出规格是否达标。根据项目使用这些检查项，不为非广告视频强塞营销结构。

有成片时看真实内容。教育类的错误不能只靠“更有动画感”解决，须先核对事实、工序及因果顺序；本地化片须检查目标语言是否自然、台词是否超时、字幕与画面文字是否一致。

## 在 Design 中沉淀 Skill

手册介绍四条路径：直接描述要创建的 Skill；做完流程后输入 `/skill-creator` 或要求总结当前对话；改进现有 Skill 后保存为自己的版本；上传文档、笔记或已有 `SKILL.md` 创建。

保留有效的任务输入、执行方法、质量标准与可复用资产，删除特定项目的临时数据。此路径可用于将本地 skill 的内容迁移到 Design；并不保证整个 Codex 文件夹和 UI 元数据都能原样导入。

社区分享是另一步外部发布：手册流程为 My Skills → 详情页 → “投稿到社区” → 官方审核。只有用户要求分享时才执行，创建本地 skill 本身不授权投稿。

## 本地开源工作流（Beta）

手册介绍官方精选 ComfyUI 工作流，含文生、首尾帧、多参考、超清、扩写、人像增强等方向。先看每套工作流的场景、输入、依赖、硬件建议、局限、来源及许可，再选轻量或完整版本；不从手册概述推导固定 GPU/显存要求。

操作链：开源与部署页选择下载 → 我的工作流 → 使用 → 画布创建 ComfyUI 工作流节点 → 修改提示词/输入素材 → 运行 → 输出连入后续节点。熟悉 ComfyUI 的用户可展开节点，导入社区工作流或新建空白流程。

部分流程完全本地运行；调用官方超清、扩写等云端增强可能消耗积分。明确哪些节点走本地、哪些走云端，不能把“本地部署”一概写成所有功能免费。下载和运行前核实存储、依赖与当前许可；未读取完整部署教程时不提供未经验证的安装命令。

手册所链详细教程：国内 `https://design.minimaxi.com/campaign`、海外 `https://design.minimax.io/campaign`。本次未读取教程正文，部署任务须另行验证。
