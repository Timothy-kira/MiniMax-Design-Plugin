# H3 参数与提示词

依据 [H3 使用手册](https://vrfi1sk8a0.feishu.cn/wiki/FIWjwgL33ipnkekzk30crmKUnIh)，读取日期：2026-10-16。以下为手册快照，执行前核对当前入口；不是 API 请求规范。

## 输出与输入限制

| 项目 | 手册所述 |
| --- | --- |
| 单次输出 | 4–15 秒，24 FPS，原生双声道带声音 |
| 文生/全能参考画幅 | 21:9、16:9、4:3、1:1、3:4、9:16；全能参考还可自动判断 |
| 首尾帧画幅 | 遵循输入图片原始长宽比 |
| 分辨率 | 768p；可升级 1440p，另列 1440p 模式 |
| 提示词 | 不超过 7000 字符，不能按 7000 个 token 理解 |
| 首尾帧图片 | 0、1 或 2 张；宽高各在 256–5760；宽高比 2:5–5:2；0 张即文生 |
| 全能参考图片 | 最多 9 张；宽高各在 256–5760 |
| 全能参考视频 | 最多 3 段；每段 2–15 秒，总计不超过 15 秒；宽高各在 256–5760，宽高比 2:5–5:2 |
| 全能参考音频 | 最多 3 段；每段 2–15 秒，总计不超过 15 秒；必须配合图片或视频，不能只有音频 |
| 混合素材 | 图片、视频、音频合计最多 12 个文件；各类别上限仍然适用 |
| 单文件大小 | 视频 50 MB、图片 30 MB、音频 15 MB |
| API 请求体 | 手册列出 64 MB，并建议素材通过 URL 传入；真实字段须查当前接口 |
| 图片格式 | JPG、JPEG、PNG、WEBP、HEIC、HEIF |
| 视频编码 | H.264/AVC、H.265/HEVC；视频内音频 AAC、MP3 |
| 独立音频格式 | WAV、MP3 |

分辨率不是任意画幅都固定短边：手册称在 16:9 到 9:16 范围内为短边 768 或 1440 像素；更宽/高画幅按约 1M 或 3.7M 总像素处理。其 21:9 示例分别为 1536×672、2976×1248。精确交付尺寸以导出结果为准。

语言方面，手册将中、英、日、韩、法、德、西等列入精准覆盖的 11 种 TTS 语言，另将阿拉伯语、泰语、印尼语、印地语等描述为 40 多种语言的衍生探索。不要把二者写成同等质量保证，未列全的 11 种也不自行补齐。

## 选择模式

- **纯文字：** 具体写主体外观、空间、动作、风格；根据叙事需要使用全景、中景、特写。
- **首/尾帧：** 一张图明确作为开头还是结尾。两张图定义起止状态，重点描述中间动作、光影和声音变化；手册说此模式不会自动加切镜，不要把它当作自动多镜头蒙太奇。
- **全能参考：** 给每个素材指定角色，例如人物身份、产品外形、场景、风格、动作、运镜、音色、音轨复用或待编辑视频。同一素材的用途可以组合，但要说清到底保留哪些属性。
- **编辑：** 指明原视频、修改对象/时间范围和要保留的画面声音。模型支持编辑不等于一定无损或逐帧精确；以生成结果验收。

## 三段式提示词

### 1. 素材说明

按实际入口的素材标签与上传顺序引用。网页手册示例使用 `@图片1`、`@视频1`、`@音频1` 等；具体编号以实际界面为准。

为素材标明人物/物体/场景、首尾关键帧、风格、构图、故事版、动作、运镜、音色、完整音轨或局部音轨复用等用途。人物多时给出能稳定指代的名字或外观。明确必须保持的脸、产品结构、品牌标识、服装等。音轨复刻若要求台词或歌词准确，应附上准确文本。没上传素材就省略这一段。

### 2. 核心创意

用一句话概括主体、地点、事件与风格，按需指定特殊运镜。需要一镜到底必须明确；手册在普通创作中提示可能默认切镜。环绕运镜可拆为 `truck left + pan right` 或 `truck right + pan left`，减少抽象描述。

### 3. 画面过程

按切镜点划分时间段，每段给出景别、主体、动作、机位变化、台词和音效。写具体可见变化，避免用抽象比喻替代画面。

- 屏幕文字、Logo 文字、标题、按钮和字幕写出准确原文。
- 角色说话写明说话人和引号内台词；画外音写明声源在画外。
- 台词跨镜头时说明在哪段开始、哪段继续；可表达 J-cut/L-cut，不必强行把一句话塞入短镜头。
- 一镜到底用连续动作和机位变化，不同时列多个“切到”镜头。
- 无背景音乐时，手册建议末尾加 `非叙事性音乐：N/A` 或 `non_diegetic_music: N/A`，再说明无需额外配乐。这是提示词写法，不是已确认可提交的 JSON 字段。
- 无对白、保留环境声、无配乐和最终静音是不同需求。手册的标准输出带声音，不凭空声称当前入口有关闭声音选项。

## 提交前与失败后

先查引用是否真实、分类/总数上限、时长、格式/编码、单文件大小、输出模式与目标画幅是否兼容。矛盾示例：既要配乐又全片禁止 BGM；既要一镜到底又多次切镜；要求严格锁脸却没有人物参考；3 秒内安排长段对白。

结果不好时优先定位原因：身份漂移补人物参考及保留特征；动作/节奏不准细化动作过程或对应参考；口型/对白问题先查台词时长和说话人；事实错误先修正脚本/分镜。字幕或音乐指令不稳定时，不能承诺再写一次禁止项必然解决；按需求考虑后期处理，并说明画面本身的问题不能靠静音解决。

## 网页与开源入口的区别

手册另链开源用户的扩写指南，**本次未读取该指南正文**。不能据网页自然语言模板杜撰完整开源 JSON schema 或 ComfyUI 节点参数。需要本地结构化提示词时先读对应工作流与官方提示词指南，核实引用标记与编号。

原手册评论区出现了 `<Picture 1>` 与内部 `ref_image_0` 的映射、声音字段和故障建议，但它们属于评论答复且未与当前开源文档交叉核实；本技能不把评论升级成通用接口契约。
