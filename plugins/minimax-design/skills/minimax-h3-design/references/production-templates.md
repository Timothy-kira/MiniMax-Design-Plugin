# 创作模板与场景选择

这些模板是依据两份手册整理的**可编辑工作模板**，不是模型的固定语法或官方原文。花括号内容必须按用户资料替换；素材标签须与实际入口相符。不要把占位符作为最终可提交内容。

## 通用 Design 需求

```text
为面向{受众}的{产品/知识主题}制作{时长}、{画幅}的视频，
用于{地区与渠道}，希望观众{理解的重点/采取的行动}。
以{具体开场事件}引出{有依据的核心卖点/知识点}，采用{风格}。
台词语言为{语言}，字幕/画面文字为{语言及准确原文}。
素材：{文件与用途}；保持{身份、产品、场景或品牌特征}。
声音：{对白、旁白、音效、配乐或静音需求}。
请形成制作方案、分镜与对应生成提示词，再按当前任务授权执行。
```

只写提示词时删除最后一句的执行请求。30 秒或更长成片须拆为多次 H3 生成再剪辑，不能直接把最终总时长当成单次输出参数。

## 通用 H3 多镜头提示词

```text
素材用途：{实际图片标签}作为{人物/产品/场景}参考，保持{关键特征}；
{实际视频标签}仅参考{动作/运镜}；{实际音频标签}用于{音色/音轨复用/情绪}。

核心创意：{主体}在{地点}完成{事件}，{可见的风格特征}，输出{画幅、时长}。

0–{a}秒：{景别}，{主体动作及可见变化}，{运镜}；
{说话人/画外音}：“{准确台词}”。{音效与音乐进出}。
{a}–{b}秒：切至{景别}，同一{主体}继续{动作}；{对应素材与声音}。
{b}–{总时长}秒：{结尾动作/画面}；显示文字“{准确原文}”。{声音收尾}。

保持{必要的一致性要求}。{其他无矛盾约束}。
```

没有对应素材、对白、画面文字时删掉相关段落。镜头数随内容决定，各段时间连续且总时长在当前单次范围内，台词能自然说完。

## 首尾帧与一镜到底

```text
{实际图片标签1}是首帧，{实际图片标签2}是尾帧。
同一{主体}从{起始状态}连续变化为{结束状态}。
中间依次发生{具体动作、物体变化与光影变化}，镜头{连续机位路径}。
全程一镜到底，主体{关键特征}稳定。
声音为{声音设计}，总时长{当前支持时长}。
```

仅一张图片时明确它是首帧或尾帧，删除另一张。相同首尾图不能保证无缝循环；循环需求须检查位置、速度、光照和声音接缝。

## 已有视频的局部修改

```text
以{实际视频标签}为待编辑视频。
保留{主体、动作、机位、节奏、其他音轨等具体内容}。
仅在{时间范围}把{明确对象/内容}改为{目标状态}，
{其他参考标签}用于{替换对象/音色/场景}。
修改原因是{目的}；预期效果为{可观察的标准}。
```

先判断应改生成内容还是在 Design 剪辑层修改；这个模板不代表模型能够精确保留每一帧。

## 场景如何落地

| 场景 | 素材与重点 | 验收要点 |
| --- | --- | --- |
| 电商产品短片 | 产品图、官方参数/卖点、使用场景；痛点或产品亮点开场，再展示过程与结果 | 外形/Logo/卖点准确，展示不能虚构实测效果 |
| KOC/社媒投流 | 产品素材、出镜人设、口语台词、真实使用场景；突出可理解的生活事件 | 人设一致、台词自然、口型与时长匹配；不编造用户真实体验 |
| 产品 UI 广告 | 真实界面图、功能与按钮原文、使用逻辑；用场景引出界面行为 | 字体/按钮文字和功能逻辑符合产品，界面演示可辨识 |
| 知识/教育 | 有依据的事实、流程与讲解顺序，按知识点拆分镜 | 先查事实与工序，再查动画、旁白、可读性 |
| 多语言本地化 | 目标市场/平台、当地语言台词、产品资料与字幕 | 不只逐字翻译；核对表达、品牌与数字读法、字幕和时长 |
| 动画/风格化 PV | 角色与场景参考、风格资产、动作节奏 | 角色跨镜头一致，风格稳定，动作有明确起承转合 |
| AR/视觉包装 | 实拍或场景参考、虚拟对象、机位与空间关系 | 虚实尺度、遮挡、透视、接触和光照一致 |

场景表综合手册中的案例分类与通用制作方法；每行的具体镜头设计与检查细化属于本技能的整理建议，不是官方成功率承诺。影视、MG 动画、游戏和工业演示也可按同一素材映射和时间过程方法编写，无需为了套表改变用户创意。

## 修改请求模板

```text
保留：{已有版本中有效的镜头/素材/声音}。
修改：{具体时间段和问题}。
原因：{商业/叙事/事实/视觉目的}。
期望：{可观察、可验收的结果}。
```
