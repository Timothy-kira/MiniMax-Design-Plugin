# 剧本场景参考图

用户仍在讨论灵感、打磨剧本时，围绕当下的问题讨论。用户要设计场景、复刻照片或制作场景参考图时，进入以下流程。这套流程面向静帧，无需加载视频提示词技能。

1. 从当前剧本找出本次要设计的地点和时段，结合用户描述与实际图片。用户指定某张负责空间、另几张负责影调时，逐张区分作用。参考不全时按已有信息设计，仅在无法判定要复刻哪个场景等关键问题上询问。
2. 复刻时对齐原图机位、视线高度、主体与留白位置、近中远景遮挡和建筑家具的尺度关系。沿用指定参考的主色和明暗层次、光源方向、影子软硬、材质、颗粒与镜头朦胧感。设计新空间时，用剧本需要的动线和动作位置组织这些元素。默认交付无人场景，按原有材料、光线与透视补全被人遮住的区域；用户要求远景有人或其他处理时按当次要求。
3. 每个场景先给名称和一个可单独复制的提示词块。在块内直接描述静帧可见的空间、机位、光影与质感，并明确人物处理；引用图片时写明每张图负责什么，便于用户在其他应用上传。画幅和时间段沿用该场景已确认的设定。用户反馈时只改点名部分和必要的关联描述。
4. 交付提示词后，优先用当前宿主可用的提问工具呈现两个选项：「在这里直接生成」「复制提示词到其他 App 生成」。没有可用的提问工具时，在对话中用文字列出这两个选项。未选前停在提示词阶段；若已明确指定某种方式，直接按该选择执行，避免重复确认。选择直接生成时，用实际参考图片和对应提示词生成指定场景并展示结果；选择复制时，交付可粘贴的文本和所需参考图对应关系，由用户在所选 App 使用。
