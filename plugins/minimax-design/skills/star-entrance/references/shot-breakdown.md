# 机位与构图选法

| 想让观众看见什么 | 摄影机怎么做 | 决定何时切的动作 |
|---|---|---|
| 人刚到，身份仍有悬念 | 让门槛或车框保留在局部特写里。拍鞋落地、衣角越过遮挡，或人物进入一束光。人物起身时，低机位可以顺势上摇。 | 如果这一拍要揭示身份，等脸越过遮挡；若想保留悬念，脚落稳就能切向听见动静的人。 |
| 有人认出了主角 | 固定近景同时容下眼睛和手边的事物。手先停，目光再抬起，给认出对方后的反应留出空间。 | 视线落定时，可以沿目光切到主角。若重点在旁观者的心情，让表情的变化走完。 |
| 主角正从某个人面前走过 | 侧向跟拍时与主角同速，让背景的人依次滑过。固定在路边时，用近处掠过的身影短暂遮住远处那张一直注视他的脸。 | 跟拍可以接下一步落脚。固定机位可以等前景移开，把那张脸重新露出来。 |
| 同一动作引起周围人的反应 | 从最先看见的人脸上拉开，带出旁边才转头的人。人群沿路排开时，可以原地横摇顺着目光扫过；想突出其中一人，可边摇边推近，在那张脸上收住。 | 接到下一道视线或下一个接连举起的动作。 |
| 想和等候的人一起看 | 从观者正面绕到侧面、肩后，让他看的方向自然进入构图。人多时可从肩背后稍稍上摇，借遮挡的缝隙看见正经过的身影。 | 观者与主角的空间关系变清楚时，就可以停下机位。 |
| 出场之后要留下整场的规模 | 高处斜俯拉开，让人物、通道和两侧的站位同框。 | 主角的去向和人群的朝向都能读清时收镜。 |

同一场里，跟拍适合看“他走到哪里了”，固定反应镜头适合看“谁发现他了”。选机位时先回答当前这个问题，场地和人物关系会决定适合的景别与节奏。
